# AGENTS.md

## Project Context

This is the Devburundi application portal repository built with React, Vite, Tailwind CSS, and Lucide React.

## Key Files

- `src/`: frontend application source code.
- `src/api/client.js`: Devburundi API and authentication client.
- `src/config/`: Configuration for registration and careers portals (`registrationConfig.js`, `careersConfig.js`).
- `vite.config.js`: Vite configuration and path alias setups.

## Working Notes

- Use `npm run dev` for local development.
- Use `npm run build` to build the production bundle.
- Maintain consistent styling and design patterns with Tailwind CSS and Radix UI components.
